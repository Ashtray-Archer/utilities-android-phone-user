# Storefront fixtures

Shop at Carpenter Bros. Hardware or the sample Indian grocery before opening a recipe. Each catalog row has a store-scoped text SKU, selling unit, price in US cents, sample available quantity, and optional inclusive months for a front display. The two tables are offline examples. All prices, stock counts, SKUs, pack choices, purchase histories, and display windows are invented. A question mark means the available quantity is unknown. Zero means sold out. The windows change display priority while preserving the full catalog.

Carpenter Bros. publicly lists tools, plumbing, paint, lawn and garden, potting/top soils, and outdoor power equipment. Toro lists the shop as a dealer. Milwaukee makes the 15-piece set used as an example. Plywood dimensions, plants, punch types, and individual brands are assumptions for the visit. The Indian store is unnamed. OM Market in the same Plymouth Road shopping area provides a local assortment reference. The fruit display window is a sample merchandising choice, independent of local harvest or availability. Spring power equipment and autumn leaf care follow the shopper's requested Michigan examples.

The display reads a merchant, local calendar month, catalog rows, and optional purchase observations. Store and SKU together resolve a purchase. A prior brush or primer purchase is evidence of an interest in painting supplies. The profile contains no project-completion field. Selected recipes may suggest matching grocery items. Quantities, substitutions, and cart choices require shopper action.

The TSV tables are the editable fixture source. Build preparation converts them into typed Idriç rows in the build directory. The same native view and ranking code consumes those rows in host and Android checks.
