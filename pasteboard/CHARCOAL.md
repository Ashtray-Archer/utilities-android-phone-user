# Charcoal default

The existing custom canvas consumes android-NDK's shared charcoal roles at
3e682fb1175beef5625dbd2418730220e49fc9bd. Its corresponding Theme.Charcoal
resources cover startup, dialogs and system bars independently of system night
mode. The checked reducer, spatial layout, clipboard authority, source bytes,
storage, package/version and signing identity are unchanged.

The CI build supplies CHARCOAL_PRESENTATION explicitly; it does not change the
checked DEX backend or other utilities' toolchain pins. Signed packaging, actual
API29/API34 visual/functional execution and physical C67 upgrade/behavior must
be recorded for the new source. Earlier dark screenshots and accepted compiler
stages do not establish acceptance of this revision.
